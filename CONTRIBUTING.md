# Contributing to AEOPIN

Thank you for your interest in contributing to AEOPIN.

## Reporting Issues
If you find a bug or have a suggestion, please use the [Aeopin_Support](https://github.com/Aeowun/Aeopin_Support) repository to file an issue.

## Code Contributions
1.  Fork the repository.
2.  Create a branch for your changes.
3.  Ensure your code follows the existing style and architecture.
4.  Submit a pull request with a clear description of what was changed and why.

## Design Principles
AEOPIN is built to be small, fast, and local-first. Contributions should respect these goals:
*   **No cloud dependencies**: Core functionality must remain local.
*   **Integrity first**: Operations that move or modify user data must be verifiable and safe.
*   **Plain and accurate**: Keep the documentation and user interface simple.
