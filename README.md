# AEOPIN

A Windows tool for keeping files, folders, links, and notes close by. Capture something when you need to. Find it again later.

## What is it?

AEOPIN is a capture tool. Drop a file, folder, text, or link into the capture window to move it into a local vault. You can search these items and drag them back out when needed.

## How to use it

### Requirements
*   Windows 10 or 11.

### Installation
1.  Download `Aeopin-portable.zip` from the latest release.
2.  Extract the ZIP to a folder of your choice.
3.  Run `Aeopin.exe`.

### Usage
*   **Show/Hide**: Press `Alt+Shift+V` to toggle the capture window.
*   **Capture**: Drag and drop any item into the window.
*   **Search**: Type in the search bar to find saved items.
*   **Restore**: Drag items out of the window or use the "Restore to original folder" option.

### Build from source
*   Build the portable distribution: `.\gradlew.bat zipDistributable`
